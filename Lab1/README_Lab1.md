# Лабораторна робота №1: Аналіз і обробка зображень

## 🎯 Мета роботи
Ознайомлення з базовими функціями роботи із цифровими зображеннями в середовищі MATLAB (за допомогою Image Processing Toolbox). У цій роботі реалізовано завантаження файлів, отримання їх технічних характеристик, перетворення колірних просторів, аналіз гістограм та прості поелементні перетворення (лінійне контрастування, створення негативу).

## 📂 Структура проекту
Для правильної роботи скрипту необхідна наступна структура директорій:
- `input/` — папка з вихідними зображеннями (`Bunch-Bananas-1.jpg`, `freshpoint-english-cucumber-scaled.jpg`, `pomodoro-1.jpg`).
- `output/` — папка, куди скрипт автоматично збереже результати обробки.
- `lab1.m` — головний скрипт MATLAB.

## 📝 Покрокове пояснення алгоритму

### 1. Підготовка середовища та завантаження файлів
Скрипт розпочинається з очищення пам'яті (`clear variables`), закриття всіх попередніх графічних вікон (`close all`) та очищення консолі (`clc`). Далі за допомогою функції `imread` зображення зчитуються з папки `input/` у відповідні змінні (`pic1`, `pic2`, `pic3`).

### 2. Відображення оригіналів
Функція `imshow` виводить оригінальні кольорові зображення на екран. Команда `figure` гарантує, що кожна картинка відкриється у новому вікні, а не перетре попередню. `title` додає вікнам зрозумілі заголовки.

### 3. Отримання технічної інформації
Використовуються команди для аналізу масивів зображень у пам'яті:
- `size` — виводить розмірності матриці (висоту, ширину та кількість колірних каналів).
- `whos` — надає розширену інформацію: розмір у байтах та клас даних (зазвичай `uint8` для зображень, де на кожен канал виділяється 8 біт).

### 4. Перетворення у градації сірого (півтонові зображення)
Для подальшої обробки (наприклад, для гістограм) повнокольорові RGB-зображення конвертуються у чорно-білі. 
- Конструкція `if ndims(...) == 3` перевіряє, чи має зображення 3 виміри (кольорове). 
- Якщо так, застосовується функція `rgb2gray`. Якщо зображення вже чорно-біле (2 виміри), воно передається без змін.

### 5. Побудова гістограм
За допомогою функції `imhist` будується гістограма розподілу яскравостей пікселів. Вона показує, скільки пікселів на зображенні мають певний рівень яскравості (від абсолютно чорного `0` до абсолютно білого `255`). Це ключовий інструмент для оцінки контрастності фотографії.

### 6. Лінійне контрастування
Якщо зображення має вузький динамічний діапазон (виглядає тьмяним або "плоским"), функція `imadjust` автоматично розтягує його гістограму на весь доступний діапазон. У результаті світлі ділянки стають яскравішими, а темні — насиченішими.

### 7. Створення негативу
Та сама функція `imadjust` застосовується для створення фотографічного негативу. Додавання параметрів `[0 1]` (вхідний діапазон) та `[1 0]` (вихідний діапазон) вказує алгоритму інвертувати яскравість: найтемніші пікселі замінюються на найсвітліші, і навпаки.

### 8. Збереження результатів
Скрипт автоматизує збереження готових файлів:
- Перевіряє наявність папки `output/` за допомогою `exist(out_dir, 'dir')`. Якщо її немає — створює командую `mkdir(out_dir)`.
- Функція `imwrite` записує матриці контрастованих та інвертованих зображень на диск у форматі `.png`.
