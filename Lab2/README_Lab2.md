# Лабораторна робота №2: Фільтрація й придушення шумів

## 🎯 Мета роботи
Дослідити ефективність різних методів просторової фільтрації для зображень, спотворених різними видами шуму. У процесі виконання роботи реалізовано штучне зашумлення зображень (гаусівський та імпульсний шуми) та їх подальше очищення за допомогою лінійних, нелінійних та адаптивних фільтрів у середовищі MATLAB.

## 📂 Структура проекту
- `Photo/` — директорія з вихідними зображеннями (`letter.jpg`, `three.jpg`).
- `Results/` — директорія, у яку автоматично зберігаються всі результати обробки.
- `lab2.m` — головний скрипт MATLAB з реалізацією алгоритмів.

---

## 📝 Покрокове пояснення алгоритму

### 1. Налаштування директорій та завантаження
На початку роботи скрипт перевіряє наявність папки `Results/` (і створює її за необхідності). Далі за допомогою `imread` завантажуються тестові зображення.

### 2. Генерування шумів (`imnoise`)
Для тестування фільтрів зображення спочатку штучно "псуються":
- **Гаусівський шум:** Імітує білий шум сенсорів (нормальний розподіл). Додається за допомогою `imnoise(img, 'gaussian', 0, 0.01)`.
- **Імпульсний шум ("Сіль і перець"):** Імітує биті пікселі або помилки передачі даних у вигляді випадкових чорних та білих точок. Додається функцією `imnoise(img, 'salt & pepper', 0.05)`.

### 3. Лінійна низькочастотна фільтрація (Згладжування)
Використовується для загального розмиття зображення та зменшення дрібних перешкод.
- Створюється матриця (маска) розміром 3х3: `ones(3, 3) / 9`, яка обчислює середнє арифметичне сусідніх пікселів.
- Фільтр застосовується за допомогою функції `imfilter`. Він трохи зменшує гаусівський шум, але робить зображення нечітким.

### 4. Лінійна високочастотна фільтрація (Підкреслення контурів)
Використовується для виділення різких перепадів яскравості (границь об'єктів).
- Задається спеціальна маска з від'ємними значеннями по краях і додатним у центрі: `[0 -1 0; -1 5 -1; 0 -1 0]`.
- Додає різкості вихідному зображенню, але також сильно підсилює будь-які існуючі шуми.

### 5. Адаптивна вінерівська фільтрація (`wiener2`)
Більш "розумний" фільтр, який адаптується до локальної дисперсії яскравості. На рівних ділянках він працює як сильне згладжування, а на границях об'єктів — слабшає, щоб зберегти різкість. 
*Примітка:* Оскільки функція `wiener2` працює лише з двовимірними матрицями (градації сірого), кольорові RGB-зображення перед її викликом автоматично конвертуються.

### 6. Медіанна фільтрація (`medfilt2`)
Це нелінійний фільтр, який ідеально підходить для усунення шуму типу "сіль і перець". Замість усереднення, він сортує значення пікселів у вікні та обирає медіану. Це дозволяє ефективно видалити різкі викиди яскравості (чорні/білі точки), повністю зберігаючи при цьому чіткість контурів. Для роботи також вимагає 2D формату.

### 7. Спеціальні фільтри (Unsharp Masking)
MATLAB надає вбудовану функцію `fspecial` для генерації стандартних фільтрів. Параметр `'unsharp'` створює маску для підвищення локального контрасту та підкреслення дрібних деталей (unsharp masking).

## 📊 Результати
Після виконання скрипту у папці `Results/` будуть згенеровані наступні файли для кожного з тестових зображень (`letter` та `three`):
- `*_gaussian` — зображення з гаусівським шумом;
- `*_sp` — зображення з шумом "сіль і перець";
- `*_lowpass` — результат низькочастотного згладжування;
- `*_highpass` — результат виділення контурів;
- `*_wiener` — результат очищення адаптивним фільтром Вінера;
- `*_median` — результат очищення медіанним фільтром;
- `*_unsharp` — зображення з підвищеною різкістю.
